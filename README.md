# My Life Hub

My Life Hub is a personal life tracker. It covers daily tasks, Quran Daily, Dars Syeikhuna, qadha prayers, personal notes, recipes and TASK DH. It syncs across devices through a Google Sheet and asks for a PIN every time it opens.

- Live: https://greyyuri97.github.io/my-life-hub/
- Developer guide: [CLAUDE.md](CLAUDE.md)
- Data and API: [docs/SCHEMA.md](docs/SCHEMA.md)
- To do: [docs/NEXT_STEPS.md](docs/NEXT_STEPS.md)

Run it locally with `python3 -m http.server 8000`, then open http://localhost:8000/.
